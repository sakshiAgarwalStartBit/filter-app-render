Filter discovery

The app looks at your actual catalog and offers every field that's realistically useful to filter by — nothing has to be set up by hand first.

Standard fieldsFilters page

Seven built-in filters are always available: price, availability, vendor, tag, product type, product category, and review rating.

Variant optionsauto-detected

The app scans your products for variant option names — size, color, and anything else you've set up — and offers each one as a filter automatically. A generic "Title" option (which Shopify adds to single-variant products) is excluded since it isn't meaningful to shoppers.

Metafieldsauto-detected

Any product metafield definition you've created in Shopify shows up as a filter option too, with color-swatch rendering when the metafield's value looks like a color name. Up to 5 metafield filters can be enabled at a time.

Order tag filtersFilters page

Turn product tags that share a prefix (for example fabric_work:) into a filter of their own, with a custom label, a list or swatch display, and single or multiple selection. Up to 5 order tag filters can be added.

Filter configuration

Everything below lives on the app's Filters page and applies instantly to the storefront once saved.

Enable & orderFilterable fields

Turn any discovered field on or off, and reorder the enabled ones with up/down controls — the storefront displays filters in exactly that order.

LayoutFilter layout

Three layouts, chosen per shop:

  • Vertical — a sidebar beside the product grid, with collapsible sections.
  • Horizontal — a row of dropdown pills above the grid.
  • Drawer — a full-height slide-out panel opened by a button, with its own heading and close control.

Mobile screens always use the Drawer style, regardless of which layout is selected for desktop.

VisibilityShow on desktop / mobile

Independent switches to show or hide the entire filter widget per device — useful if you only want filtering on desktop, for example.

Products per pagePagination

Set once in the admin; the storefront then shows that many products at a time, with a "Load more" button and a "Showing X of Y products" counter underneath.

Clear-all labelClear all button

The text on the button that resets every active filter is fully editable — defaults to "Clear all" but can be renamed to match your store's voice.

Collection and search setupsFilters page

Collection pages and search results each have their own filter list and layout settings, so you can offer different filters in each place.

Product countsLayout & display

A switch controls whether each filter value shows how many products match it, for example "XL (3)".

Live previewFilters page

A Preview button shows how the filters will look with your current layout and style settings before you save, and the Customizer can be opened as a pop-up straight from the Filters page.

Storefront experience

What a shopper actually sees and does when they land on a collection, the all-products page, or search results.

Universal coverage

The same block works on individual collection pages, the /collections/all page, and search results — search queries the catalog directly and applies the same admin-configured filters.

On the search page, the theme's own default result grid is automatically hidden once the app's results take over, so shoppers don't see two product lists.

Live filtering

Checkbox filters, a two-thumb price range slider, and color swatches, each showing a live product count. Sections in Vertical and Drawer layouts collapse and expand independently.

Sort

Featured, best-selling, price (low–high / high–low), and title (A–Z / Z–A).

Shareable filter state

Active filters and sort are written into the page URL, so a filtered view can be bookmarked, shared, or linked directly — and works with the browser's back and forward buttons.

Product cards

Each card shows a title (truncated to one line if long), price, a sale badge when the item is discounted, and a second product image that fades in on hover, if one exists.

Cards with variants show clickable size pills and color swatches — selecting one updates the card's price, image, and which variant "Add to cart" will add.

Cart & checkout

Adding to cart happens without leaving the filtered grid.

Quick add to cart

Every card has an "Add to cart" button that adds the selected (or first available) variant directly, with an in-progress and confirmation state. Out-of-stock products show a disabled "Sold out" button instead.

Cart drawer & count sync

After adding an item, the header's cart count updates immediately and the cart drawer's contents refresh to show the new item, with no full page reload. This includes the first item added to an empty cart.

count sync — live drawer, existing items — live drawer, first item added to empty cart — live

If a theme's cart drawer can't be recognised, the page reloads once after the first add so the drawer is never left showing stale contents.

Wishlist & reviews

Extras that sit alongside the filters.

WishlistLayout & display

When switched on, every product card gets a heart icon so shoppers can save products. Customers who are logged in have their wishlist saved to their account; guests get a wishlist that stays in their browser.

A separate "Wishlist" app block shows a shopper's saved products as a grid, using the same cards as the filter results. Add it to a page in the theme editor.

Merchants can see what customers have saved on the app's Wishlists page: the total saved items, how many customers have a wishlist, the most-saved products, and a list of customers with a link to each customer in the Shopify admin.

Review ratingsReviews page

Star ratings are read from a product metafield, so they work with your existing review app. The defaults match Judge.me; on the Reviews page you can enter a different app's namespace and keys. The ratings appear on product cards and can also be used as a filter.

Appearance

A dedicated Customize page controls how the filter widget looks, separate from what it does — changes apply live, with no code edits.

Customize pageapp menu → Customize
  • Sidebar background color
  • Filter value text — size, weight, transform, color
  • Filter heading text — size, weight, transform, color
  • Clear-all button — size, weight, radius, colors
  • Filters toggle button — size, weight, radius, colors
  • Add to cart button — size and colors, set separately for collection and search pages
  • Products per row in the grid
  • Color swatch shape — circle or square
  • Custom CSS, separate for collection and search pages

Performance

How the app keeps the storefront fast.

Product cacheLayout & display → Product cache

Collection product data is saved for up to 10 minutes, so most shoppers see results without the app having to reload the whole collection from Shopify. The saved copy is also cleared automatically whenever a product changes.

Product changes (such as price, stock or new products) can take 5-10 minutes to show up in the filters. To see a change straight away, use Clear cache.

Plans & trial

What's free, what's paid, and what happens when the trial ends.

Free trial

Every live store gets a 7-day free trial that starts when the app is installed, with every feature available. The dashboard shows how many days are left.

Paid planPlans page

After the trial, the app continues on a single Paid plan at $4.99 per month. There are no feature tiers: the Paid plan includes everything in this guide, so nothing is held back for a higher plan.

Nothing is charged automatically when the trial ends. The merchant approves the plan from the app's Plans page, which opens Shopify's own approval screen. Until they do, the storefront filters pause and the merchant's settings are kept, and the filters start working again as soon as the plan is approved.

Development stores

Shopify never bills development stores, so they get full access with no trial and no payment. If a development store later goes live, its 7-day trial starts at that point.

Current plan

The dashboard shows the store's current plan next to the welcome heading: Free trial, Paid, Development store (free), or Trial ended.

Security & data

How the app is built to keep store data safe.

Server-side only

All Shopify Admin API access happens on the app's own server. No API key, access token, or Storefront API credential is ever sent to a shopper's browser.

Scoped by shop

Every storefront request is checked against the requesting shop's own installation before any data is returned.

Uninstalling the app

When the app is uninstalled, its access to the store is removed straight away. The store's saved data (filter settings, style settings, wishlists and cached products) is kept for 48 hours, then deleted automatically when Shopify sends its store-data erasure request. If a merchant reinstalls within those 48 hours, their settings are still there.

Customer data requestsPrivacy compliance

The app handles Shopify's customer data request and customer erasure requests. The only customer-linked data it holds is wishlist items, and those are deleted on an erasure request.

Getting started

  1. Choose your filters Open the app's Filters page, turn on the fields you want, and drag their order to match how you'd like them to appear.
  2. Pick a layout Select Vertical, Horizontal, or Drawer — preview how each looks on your storefront before committing.
  3. Match your brand Visit the Customize page to set colors, fonts, and button styling so the widget feels native to your theme.
  4. Add the block In the theme editor, add the "Collection filters" app block to your collection, all-products, and search templates. The dashboard's Setup Guide has a button that opens the theme editor with the block ready to add.
